FASE 1 — PUBLICAR PLATILLO DEL DÍA (~11:00 AM, L-V)
================================================================================

  RESPONSABLE: Pivote del día
  TIEMPO: ~1 minuto

  1. Pivote recibe platillo del día del restaurante (WhatsApp de siempre)
  2. Pivote abre la app → sección "Hoy"
  3. Escribe el nombre del platillo del día
     Ej: "Cortadillo de Puerco al Chile Pasilla"
  4. Toca [ PUBLICAR ] → Telegram notifica al grupo

  ⚠️  F1 — Pivote no disponible:
      Cualquiera del pool de 4 puede publicar. Misma URL, sin login.

FASE 3 — LA COMANDA (automático a las 12:30 PM)
================================================================================

  RESPONSABLE: Sistema compila → Pivote revisa y envía

  1. A las 12:30 el sistema cierra la ventana de pedidos
  2. Cualquiera del pool abre:  [URL]/comanda
  3. Ve el resumen formateado listo para copiar:

  ┌────────────────────────────────────────────────────┐
  │  📋 COMANDA — QUIERO MÁS+                          │
  │  Lunes 26 de Mayo · 10 pedidos                    │
  │                                                    │
  │  1. Ana     │ Milanesa de Res       │ Arroz+Frijol │
  │  2. Juan    │ Platillo del Día      │ Puré+Nopales │
  │  3. Carlos  │ Enchiladas Suizas     │ Arroz+Puré   │
  │  4. ...                                            │
  │  ─────────────────────────────────────────────────│
  │  RESUMEN:                                          │
  │  Milanesa de Res x2 · Enchiladas x3 · ...         │
  │                                                    │
  │  [ 📋 COPIAR COMANDA ]                             │
  └────────────────────────────────────────────────────┘

  4. Pivote toca [ COPIAR COMANDA ]
  5. Abre WhatsApp → chat del restaurante → pega → edita si quiere → Enviar ✅

  VENTAJAS DE ESTE DISEÑO:
    ✓ Pivote siempre revisa antes de enviar
    ✓ Puede agregar notas al restaurante
    ✓ Puede corregir algo de último momento
    ✓ Sin riesgo de envíos automáticos incorrectos
    ✓ El restaurante recibe WhatsApp de siempre (nada cambia para ellos)

  ⚠️  F6 — Error de transcripción:
      IMPOSIBLE. La compilación es automática desde las selecciones.

  ⚠️  F7 — Alguien no pidió:
      La comanda muestra claramente "SIN PEDIDO" para esa persona.
      Pivote decide al momento de revisar.

================================================================================
FASE 4 — FALTANTES (si el restaurante reporta un problema)
================================================================================

  RESPONSABLE: Restaurante avisa → Sistema actúa (si hay Plan B)
                                  → Pivote gestiona (si no hay Plan B)

  CASO A — Con Plan B definido (usuario llenó la sección opcional):
    Restaurante: "No hay Enchiladas"
    Sistema identifica afectados → sustituye con Plan B automáticamente
    Pivote ve en la comanda: "Ana: Enchiladas → Milanesa (auto-cambiado)"
    Pivote copia comanda actualizada → pega en WhatsApp → Enviar ✅
    Nadie fue contactado.

  CASO B — Sin Plan B (usuario eligió "Da igual" o no lo llenó):
    Restaurante: "No hay Enchiladas"
    Pivote notifica al usuario afectado (WhatsApp de siempre o Telegram)
    Usuario responde → Pivote edita la comanda manualmente en la vista
    Pivote copia y envía comanda actualizada

  ⚠️  F8 — Usuario no responde el cambio:
      Con Plan B → no existe este problema.
      Sin Plan B → igual que hoy, pivote resuelve.

  ⚠️  F9 — Backup también agotado:
      Sistema lo detecta → pivote gestiona manualmente ese caso.

  ⚠️  F10 — Varios afectados por el mismo faltante:
      Con Plan B → sistema resuelve todos en paralelo, instantáneo.
      Sin Plan B → pivote notifica a todos simultáneamente.

================================================================================

  Restaurante prepara y entrega.

  ⚠️  F11 — Comida incorrecta:
      Pivote tiene la comanda en la app como referencia para verificar.
